Tips for best results
    

  • Hold the phone close to the speaker that plays the beeps (about 10–30 cm / 4–12 in), in a quiet room.
    • 

  • Start recording a moment before the beeps begin and stop a moment after.
    • 

  • Any pitch from about 150 to 4000 Hz works. If the pitch changes during the recording, each pitch is read separately.
    • 

  • Any speed from about 5 to 50 words per minute works. The speed is measured automatically, even if it changes.
    • 

  • Strong echo (a big empty room, phone far from the speaker) can blur very fast beeps together. Move closer.
    • 

  • If the answer looks wrong, tap “Save this recording” and keep the file so it can be checked.
